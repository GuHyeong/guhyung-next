# 구형의 다음

권구형의 도구·게임 작업실.

아이디어를 도구와 게임으로 실험하고, 배운 것을 기록하는 제작자의 카드형 포트폴리오입니다.

## 홈페이지

GitHub Pages에서 `main` 브랜치의 루트 폴더를 배포합니다. 홈페이지 파일은 `index.html`입니다.

## 기능

- 7개 작업 카드와 상세 보기
- 쓰임, 놀이, 제작 노트, 생각 노트 필터
- 검색, 정렬, 격자/목록 전환
- 브라우저에 저장하는 꺼내둔 카드
- 모바일 반응형 화면

## 수정

`index.html` 안의 `WORKS` 배열에서 카드 내용을 수정할 수 있습니다. 표지는 직접 만든 SVG 개념 그래픽이며 실제 작업의 실행 화면이 아닙니다. 각 작업의 확인된 상태와 미확인 범위를 구분했습니다.

외부 라이브러리와 추적 도구를 사용하지 않습니다. 개인 연락처나 사적인 AI 대화 링크는 포함하지 않았습니다.
